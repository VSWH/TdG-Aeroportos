# TdG-Aeroportos
Modelagem da distância de entre aeroportos no Brasil utilizando um grafo não direcionado


Na elaboração do grafo, foram utilizados dados de aviação desde 2000 até 2025. 
Os dados foram obtidos a partir da ANAC (Agência Nacional de Aviação Civil), em uma publicação no Kaggle.
Segue o link:

https://www.kaggle.com/datasets/sturarods/anac-national-civil-aviation-agency-2000-2025
